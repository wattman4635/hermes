Privacy Policy

Hermes — personal Google Workspace agent. Last updated: 7 November 2026.

Limited Use disclosure.
Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

1. Scope of this policy

Hermes is a private, single-user application operated by one individual for their own Google account. It is not a commercial product, has no other users, and is not distributed to the public. This policy explains what Google user data Hermes accesses, how that data is used, where it is stored, and how it can be deleted.

2. What data is accessed

After the operator grants consent through Google's OAuth 2.0 flow, Hermes may access:

  • Gmail — message contents, headers, labels, and attachments of the operator's own mailbox.
  • Google Calendar — event titles, times, locations, descriptions, and attendees on the operator's own calendars.
  • Google Drive — file names, metadata, and contents of files the operator owns or can access.
  • Google Sheets — spreadsheet contents the operator requests be read or written.
  • Google Docs — document contents the operator requests be read or appended to.
  • Google Contacts — the operator's contact names and email addresses.
  • Account identity — the operator's email address, used to identify the authorized account.

Hermes accesses only the operator's own data. It does not access the data of any other Google user except where the operator explicitly instructs an action involving a correspondent (for example, sending an email to a recipient).

3. How data is used

Data is used solely to carry out actions the operator explicitly requests, such as searching mail, drafting or sending a message, creating a calendar event, or reading a document. Every Google API call is initiated by a direct instruction from the operator in the course of using the assistant.

Google user data is not used or transferred for:

  • advertising, marketing, or profiling;
  • determining creditworthiness or lending purposes;
  • sale to any third party;
  • training or improving generalized or foundation machine-learning models.

4. Storage and retention

Hermes runs locally on hardware controlled by the operator. Data retrieved from Google APIs is held in memory only for the duration of the task and is not persisted to any remote server. The only long-lived credential stored is an OAuth refresh token, kept in a local file readable solely by the operator's own operating-system account.

No Google user data is retained after a task completes, beyond the operator's own mailbox and drive, which remain under the operator's control in their Google account.

5. Sharing and disclosure

Google user data is not shared with, sold to, or disclosed to any third party. It is not transmitted to the AI model provider as bulk data; only the specific text needed for a requested task may be included in a prompt to the language model that powers the assistant, and that processing is limited to producing the requested result.

Data may be disclosed only if required by applicable law, or with the operator's explicit instruction.

6. Security

Credentials are stored with file permissions restricted to the operator's user account. All communication with Google APIs uses HTTPS. Access tokens are short-lived and refreshed automatically; the refresh token can be invalidated at any time.

7. Deleting your data and revoking access

Access can be revoked, and all stored credentials invalidated, in either of two ways:

  • Visit myaccount.google.com/permissions, select Hermes, and choose Remove access.
  • Delete the local token file on the machine where Hermes runs.

Once access is revoked, Hermes can no longer read or act on the account, and the stored refresh token stops working immediately. Because no Google user data is stored outside the operator's own Google account, revoking access is sufficient to remove all retained data.

8. Children

Hermes is not directed at children and is not used by anyone other than its single adult operator.

9. Changes to this policy

Any change to this policy will be published on this page with an updated date. Because Hermes has a single user, material changes will also be communicated to that operator directly.
